# Contributing

Work in a small vertical slice that produces demonstrable user or operational value. Start from an
approved issue meeting the Definition of Ready in [team ownership](docs/team-ownership.md), branch
from current `main`, and keep commits reviewable.

Before requesting review, run the checks in [development.md](docs/development.md), update tests and
documentation, complete the pull-request template, and confirm no `.env`, credentials, real GPS
data, `.osm.pbf`, or `.osrm*` files are staged. At least one peer approval and green required CI are
needed. Architectural or stack changes require an ADR.
